QUBO Pipeline

Decision variables

ys = 1 if station s is opened; otherwise 0.

xe,s,t = 1 if EV e charges at station s during time t; otherwise 0.

22 actual binary QUBO variables.

Formula: Nqubo = nst + Σe (nst × |We|)

Objective

Total objective = Electricity cost + Detour / travel cost + Infrastructure cost + Grid stress penalty
Mathematical formulation

min Σ priceₜxₑₛₜ + Σ detourₑₛxₑₛₜ + Σ open_costₛyₛ + stress(loadₜ)

Charging demandEach EV receives its required charging.
Time windowEVs charge only in allowed slots.
Station capacityNo station serves too many EVs at once.
Grid capacityTotal load stays within each grid limit.
CouplingOpening a station determines which charging assignments are possible.

QUBO transformation

Constraints are converted into penalty terms and incorporated into a QUBO.

min zᵀQz + c = objective + λ · constraint penalties
Problem↓Objective + Constraints↓QUBO↓Ising↓Cost Hamiltonian↓QAOA
QUBO is the common optimization formulation; classical and quantum methods evaluate this same formulation.

Hamiltonian transformation

Ising transformation: Binary variables are mapped to Pauli-Z spin operators to construct the problem Cost Hamiltonian:

x_i = (1-Z_i)/2
QUBO↓Ising representation↓Cost Hamiltonian↓QAOA / Quantum optimization

QUBO → Ising representation → Cost Hamiltonian  ·  Cost Hamiltonian → QAOA

Conceptual quantum mapping workflow. Parameterized QAOA ansatz circuits explore this Cost Hamiltonian on Qiskit Aer.
